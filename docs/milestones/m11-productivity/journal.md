## 2026-11-11 — Part 1: command palette
- Built: `cmux-core::palette` (`score`, `rank`; cmux's exact / whole prefix / word prefix / substring / short-token subsequence scores, plus cmux's exact-word 6200 case that the plan's list left out); `PALETTE` table in `actions.rs` with cmux's `displayName` titles and a sync test against `DEFAULTS`; `Hints` global (first bound chord per action, shown via `keybindings::display`, e.g. `Super+Shift+P`); `window_view/palette.rs` overlay (rows are `Row { title, keywords, hint, run: Run }`, `Run` = `Action | Workspace | Surface`, so Part 2 adds a variant and pushes rows in `palette_rows`). README section added; KDE's Super+P display shortcut noted.
- Deviations from the plan: the switcher binding is cmux's `goToWorkspace`, not `commandPaletteSwitcher` (that name is only cmux's notification name). Ctrl+N/Ctrl+P are cmux's remappable `commandPaletteNext`/`commandPalettePrevious`, bound only in the `CommandPalette` key context (so the terminal keeps Ctrl+N/P); both are left out of the palette table along with the numbered actions. Hints are `Super+Ctrl+Alt+Shift+Key` order and show gpui's key (`Super+Ctrl++` for equalizeSplits, `Super+}` for Super+Shift+]).
- Deviations from the Swift app: no diacritic folding (lowercase only), no typo/initialism/stitched prefixes, highlighting, recency, `when` gating. Keywords are the config action name for commands and `workspace` / `surface tab` for switcher rows. The palette also closes when focus leaves it (a shortcut that focuses a terminal, e.g. Super+N while open). Shortcuts handled on the root view (Super+N…) still fire while it is open, as macOS menu shortcuts do in cmux.
