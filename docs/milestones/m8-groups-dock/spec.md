# M8 groups-dock — Spec

**Goal:** keep many agent workspaces organised.

## Scope
- Workspace groups: collapsible named sidebar sections with an anchor workspace, `+` to spawn inside, rename/pin/ungroup (as cmux `docs/workspace-groups.md`).
- Dock: right sidebar holding terminals with the same split system as the main area (as cmux `docs/dock.md`, terminals only, no browser).

## Exit criteria
1. Group behaviour (anchor, collapse, spawn, ungroup) matches cmux's doc.
2. Dock holds split terminals that survive workspace switches.
